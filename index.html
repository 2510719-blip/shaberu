일본어 표현한국말(뜻)

마이크를 쓸 수 없어요

  1. 아래 "주소 복사"를 누른 뒤 크롬 새 탭 주소창에 붙여 넣어 열어요. 마이크 허용 창이 뜨면 "허용"을 눌러요.
  2. 허용 창이 안 뜨면 주소창 왼쪽 자물쇠(또는 설정 아이콘) → 권한 → 마이크 → 허용으로 바꿔요.
  3. 그래도 안 되면 휴대폰 설정 → 앱 → Chrome → 권한 → 마이크 → 허용으로 바꿔요.
마이크 버튼이 안 될 때: 키보드 음성 입력
  1. 아래 칸을 눌러 키보드를 띄우고, 키보드 언어를 일본어(日本語)로 바꿔요.
  2. 키보드의 마이크 모양을 눌러 문장을 말해요.
  3. 글자가 들어오면 "채점하기"를 눌러요.
